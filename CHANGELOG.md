# Changelog

All notable Kirugram-specific changes are documented here.

Kirugram is maintained as a community rebrand based on the Kurigram project and the
Pyrogram project lineage. This changelog records changes made for Kirugram; it does
not claim authorship of inherited upstream code.

## 2026-11-27

### Project identity and maintenance

- Established the `kirugram` Python import namespace for the Kirugram distribution.
- Added Kirugram-specific project branding and repository documentation.
- Added Kirugram contribution guidance and project notices while retaining upstream
  attribution and the applicable LGPL-3.0-or-later license.
- Added separate Kirugram community-license drafts scoped only to original
  KIRU-OP-owned contributions that are expressly marked as covered.
- Updated package maintainer metadata to include KIRU-OP without removing upstream
  authors or maintainers.
- Removed the inherited Kurigram community-chat URL from package metadata rather
  than presenting it as an official Kirugram community link.

### Compatibility and licensing

- Existing upstream code remains subject to its original copyright notices and
  applicable license terms.
- The custom Kirugram license drafts do not replace the GNU LGPL license files
  and do not relicense inherited upstream code.
